# 파이썬으로 배우는 알고리즘

---

## 목차

| 파일 | 주제 |
|------|------|
| `01_time_complexity.py` | 시간복잡도 & 빅오(Big-O) 표기법 |
| `02_recursion.py` | 재귀 (Recursion) |
| `03_selection.py` | 선택 정렬 (Selection Sort) |
| `04_divide_and_conquer.py` | 분할 정복 (Divide and Conquer) |
| `05_bubble_sort.py` | 버블 정렬 (Bubble Sort) |
| `06_insertion_sort.py` | 삽입 정렬 (Insertion Sort) |
| `07_merge_sort.py` | 합병 정렬 (Merge Sort) |
| `08_quick_sort.py` | 퀵 정렬 (Quick Sort) |
| `09_binary_search.py` | 이진 탐색 (Binary Search) |
| `10_dynamic_programming.py` | 동적 계획법 (Dynamic Programming) |
| `11_greedy.py` | 그리디 알고리즘 (Greedy) |
| `12_backtracking.py` | 백트래킹 (Backtracking) |
| `13_bfs.py` | 너비 우선 탐색 (BFS) |
| `14_dfs.py` | 깊이 우선 탐색 (DFS) |

---

## 학습 흐름

```
시간복잡도 → 재귀
    ↓
정렬 알고리즘 (선택 → 버블 → 삽입 → 합병 → 퀵)
    ↓
탐색 알고리즘 (이진 탐색 → BFS → DFS)
    ↓
고급 기법 (분할 정복 → 동적 계획법 → 그리디 → 백트래킹)
```

---

## 실행 방법

```bash
python 01_time_complexity.py
```
